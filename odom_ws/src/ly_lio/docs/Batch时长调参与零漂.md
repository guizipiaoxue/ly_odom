> 历史记录，结果属于2026-10-13的24维Batch点到面模型及当时的地图/外参/噪声参数。
> 当时用户指定0.1ms；2026-10-17的24维固定外参模型保留实际配置的1ms并统一C++缺省，
> 不沿用本次搜索的精度保证。现行定义及验证边界见[当前实现约定](建模.md#本项目当前实现约定)。

2026-10-13。仅调整 `lidar_batch_duration`，所有候选严格满足 `0 < duration < 0.010 s`。
保持真正24维状态、原地图参数、IMU噪声、安装外参、原始输入与扫描末点输出。

## 时长的含义

参数是从该批第一个有效点起算的时长上限，不是固定周期。
下一条IMU观测或扫描结束先到时，当前批提前结束；与IMU同时间戳的点在IMU更新之后处理。
批末采用真实点时间，统一去畸变、冻结先验并联合更新一次，随后继续下一批。

当前MID360原始IMU约200Hz，间隔并非严格5ms。因此6～9.9ms的配置常会先遇到IMU分界，
实际批长可能相同。改变Batch时长不会改变约10Hz的扫描末点输出频率，
也不能消除驱动收满原始一帧后才交付的等待时间。

参数读取新增专用范围检查：非有限值、非正数、10ms及以上均拒绝启动，
错误消息明确指出必须严格小于10ms。固定激光→IMU外参、两路转换和PTP职责不变。
直接调用生产参数读取的10项边界检查通过：-1、0、0.010、0.020秒、NaN及正无穷被拒绝，
0.0001、0.002、0.0099、0.009999秒合法。

## 评价与筛选方法

训练使用完整静止录包 `odom_20261012_213853_3614d9c3`，固定600秒窗口
`[1791812341900140032,1791812941900140032] ns`。
这份录包此前是实机验证数据，在本轮主动搜索Batch参数后属于训练数据。
初始候选为0.1、0.25、0.5、0.75、1、1.5、2、2.5、3、4、5、6、8、9.5、9.9ms，
仅根据训练结果做有限的邻域细化，再冻结候选进行跨录包回归验证。
粗筛最小RMS在0.1ms短端边界，因此追加0.005、0.01、0.025、0.05、0.075、0.125、0.15ms。
细筛最小值再次落在0.005ms边界，于是补查0.001、0.0025ms的近单点极限。
两组输出相同且RMS高于0.005ms，最终共24个候选。两次扩展均只依据训练结果，
完成后才冻结候选、开始其他录包验证。

主要指标为全600秒位置RMS，参考全程首5秒平均位置；同时报告最大偏移、
首末各5秒均值位置差和姿态变化，避免只挑最后一个时刻恰好回到原点的参数。
所有候选使用相同生产核心、原始消息和SQLite接收顺序、初始化前缀、安装外参。
逐组检查输入计数、输出时间序列、重建/丢弃计数及协方差有限性。

2ms基线6041组完整输出与此前离线结果所有列逐数相同；
固定窗口6000条，末端0.560909cm、最大1.146977cm、RMS0.492328cm，
末端姿态0.021825°、最大0.080514°。
现场实测0.6215cm末端属于ROS实时调度与不同初始化前缀，不混入此次参数同源比较。

跨录包验证使用191716和190342两份静止60秒数据、211347固定中心云台旋转数据。
这些录包曾参与历史开发，211347还参与了安装杆臂拟合，因此属于回归验证，
不当作完全未见数据或独立机械真值。动态旋转的姿态变化不作为静止零漂。
本轮使用已有录包，不启动实机或更改PTP；不以有限网格搜索声称全场景全局最小零漂。

原始配置、CSV、JSON、图和搜索计划保存在各录包的 `analysis/batch_duration_20261013/`。
临时回放、测量和验证程序完成后删除，不加入包内测试或分析代码。

## 最终采用0.1ms

24组搜索中的位置RMS最小值出现在0.005ms：0.458073cm；
**用户最终指定采用0.1ms（100µs），已写入MID360默认配置。**
0.1ms的RMS为0.461551cm，与搜索最小值相差0.00348cm。
用户选择发生在搜索后，0.1ms的跨录包结果作为指定配置的回归检查，不作为再次挑选依据。

| 600秒同源离线指标 | 原2ms | 采用0.1ms |
|---|---:|---:|
| 末端位置偏移cm | 0.560909 | 0.528622 |
| 最大位置偏移cm | 1.146977 | 1.116496 |
| 位置RMS cm | 0.492328 | 0.461551 |
| 末端姿态变化° | 0.021825 | 0.022102 |
| 最大姿态变化° | 0.080514 | 0.092728 |
| 姿态RMS ° | 0.032693 | 0.033124 |

位置RMS降低6.25%，末端和最大偏移分别降低5.76%和2.66%；姿态指标略有退化，
不能称位置与姿态全面改善。全量输入6056帧云、121127条IMU，24组输出均6041条、
固定窗6000条，时间戳一致，无重建/丢弃，协方差正定且对称。
8、9.5、9.9ms的完整输出逐数相同，验证了受IMU分界限制的长批次平台区。
同一扫描内有效点的最小原始间隔4934ns、double表达最小4768.37ns，
1和2.5µs每批至多一个原始点，完整输出相同；该近单点极限RMS为0.466988cm。
