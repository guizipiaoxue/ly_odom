## 残差定位与模型边界

1. 连续启动实际消除了“初图不正常传播再重设状态”的流程差异，但没有消除首次激光校正。种图内部小于1mm而首匹配校正数mm，支持下一步检查初图几何、先验与地图之间的一致性；不支持继续只延长等待。
2. 同源600秒连续启动约2698万候选、1795万匹配，约394万Batch；没有失败Batch。批内重复支持使用占约4.37%，相邻Batch复用独立支持占约1.75%。本轮处理相关性的范围是0.1ms内，不能把它当成解决长期反复使用地图信息的模型。
3. 平均新增平面方差约0.000280m²，当前点残差方差为0.001m²；它确实改变了观测权重，但同源结果表明改善不够。仅批内共享修正的额外收益很小，长期地图误差和状态—地图相关性P_xm仍未建模。
4. 124845末5秒连续启动匹配残差RMS约1.06cm、失败Batch为0，估计IMU速度RMS约6.42cm/s，杆臂速度RMS约0.17cm/s。因此明显速度波动主要已经存在于滤波状态，不能只靠换baselink杆臂输出消掉。残差小不能证明闭合正确；本地地图与状态可能一起累计偏差。
5. 原始IMU时间递增、全程无重复倒退；回放公共窗输出stamp一致，点数与匹配计数充分，不支持把本轮厘米级漂移直接归咎于丢整段数据。PTP正确不等于物理采样时延已标定，单靠这些静止/近闭环包还不能排除动态时延、内部外参或传感器系统误差。

下一轮应先围绕残差做有界验证：保留地图平面/局部建图状态的持久不确定性及其与当前状态的相关性（例如Schmidt地图平面或有限窗口状态），覆盖跨Batch复用；初始化若要改先验，应通过单姿态可观性推导g/倾角/ba联合协方差，不能拍一个更小的P。动态时延/内部外参需要有激励的运动与独立约束再辨识。本轮未实现这些后续模型，也没有继续搜索噪声或门限来凑终点。
