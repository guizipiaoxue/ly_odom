# 云台 yaw 转心外参标定（2026-10-11）

使用 `bags/odom_20261011_211347_1014ce5a`。用户确认底盘始终固定，云台只绕竖直
Z 轴旋转，雷达刚性连接于云台。本次仅标定雷达相对于旋转中心的**水平有效杆臂**。
这不是完整六自由度机械外参标定，也不把旋转云台姿态当作固定底盘姿态。

## 使用的变换与结果

唯一业务配置仍为 `pcl_ws/config/lidar2baselink.yaml`，约定为
`p_baselink = R_BL * p_lidar + t_BL`。录包 `/tf_static` 证实旧配置确实生效；
本项目当前内部 lidar→IMU 外参是单位阵，静态 TF 与这份安装 YAML 一致。

| 平移分量 | 旧值（m） | 新值（m） |
| --- | ---: | ---: |
| X | 0.006526397018083437 | -0.006009591012854143 |
| Y | -0.1525299386029563 | -0.14915516181160768 |
| Z | 0 | 0 |

旋转矩阵保持原值。运动中相对 roll/pitch 最大仅为 0.432°/0.286°，主要为 yaw；
去均值旋转设计矩阵的奇异值为 18.466、18.466、0.03345，轴向平移约束很弱。
不能利用微小姿态噪声给高度赋值，绕轴转动也无法确定完整安装旋转及 yaw 零位。

## 拟合方法

取全部 420 组已发布 baselink 位姿，跨度 41.8999 s。令其位置、旋转为 `p_i, R_i`，
在旧 baselink 中求指向固定转心的修正向量 `d=[dx,dy,0]` 和固定世界位置 `c`：

```text
min Σ || p_i + R_i*d - c ||²
d = [0.01253598803093758, -0.0033747767913486202, 0] m
t_BL_new = t_BL_old - d
p_i_new = p_i_old + R_i_old*d
```

对位置及旋转去均值后进行等权最小二乘，不用单一首帧的噪声来拟合转心。
参数写回符号是 `t_old-d`。位置评价再分别减去各自首个有效输出，并用各自初始
baselink 轴表达，与终端 B0 显示口径一致。

当前安装外参只作用于输出及转换节点，滤波直接接原始雷达/IMU；因此对原轨迹施加
上述刚体变换，是同一滤波结果使用新外参时的精确输出，不需要重新拟合地图。
未更改传感器时间、滤波参数、内部 lidar→IMU 外参或终端显示逻辑。

## 同段效果与分段检验

| 指标（420 组，完整窗口） | 原外参 | 新外参 |
| --- | ---: | ---: |
| 距初始 baselink 最大偏移 | 5.573 cm | 3.938 cm |
| 距初始 baselink 的位置 RMS | 2.166 cm | 1.405 cm |
| 相对各自全段位置均值的 RMS | 1.749 cm | 1.300 cm |
| 最后一帧距初始位置 | 0.507 cm | 0.510 cm |

RMS 表示位移向量范数的均方根，末帧数值不是末 5 s 均值。完整窗口包含拟合样本，
不能将表中数字称为独立新数据精度。修正主要降低旋转期间的摆动，末端值并未改善。

用传感器时间中点分半，另按已发布 baselink 角速度 `wz>0.08 rad/s` 与
`wz<-0.08 rad/s` 分成正反转；每次只在训练部分求 d，在另一部分检验。
下表 RMS 均相对于检验部分自己的位置均值：

| 拟合部分 → 留出检验部分 | 检验样本 | 原 RMS | 新 RMS |
| --- | ---: | ---: | ---: |
| 前半 → 后半 | 210 | 1.940 cm | 1.458 cm |
| 后半 → 前半 | 210 | 1.477 cm | 1.320 cm |
| 正转 → 反转 | 106 | 1.758 cm | 1.299 cm |
| 反转 → 正转 | 95 | 1.813 cm | 1.409 cm |

四组均改善；最终配置用完整窗口重拟合。两方向拟合 dxy 分别为
`[11.102,-3.611] mm`、`[11.745,-4.527] mm`。两秒块重采样 1000 次得到 dxy
2.5%～97.5% 分位分别为 X `[9.33,16.81] mm`、Y `[-5.89,-0.29] mm`，
仅描述本段对取样的敏感性，不是机械测量精度或独立置信保证。

## 时间链路与剩余误差

- 420 组 Odometry/TF 时间戳逐条一致，位姿数值差为零。
- 所有输出均匹配各扫描最后有效点，最大整数时间差 512 ns，属于 double 换算精度。
- 输出约 10 Hz、原始 IMU 约 200 Hz，输出窗口内无时间回退和大段缺失。
- 原始 8529 条 IMU 全部有转换后相同 stamp；转换流多出的 604 条来自更早开始录制。
- 启动日志中的 0.210 s IMU 缺段重置发生在首个里程计输出前，未跨重置拼接轨迹。

这些检查没有证明物理采样时延为零。新外参下仍有最大约 3.94 cm 动态残差，可能含
运动估计、点云配准、内部传感器外参或物理时延误差，不能继续调安装平移将其强行归零。
以后应以另一份固定底盘、慢速正反转并停顿的录包独立验收；若要标高度或完整安装角度，
需要额外轴向激励及已知几何/姿态参考。

## 结果文件与生效方式

ROS 2 正常速度回放中，新配置通过 `scripts/odom.sh start_lidar:=false record_bag:=false`
启动；同时在独立命名空间运行旧配置节点，共用相同原始点云/IMU，在隔离 ROS 域内比较。
412 组共同位姿的新旧关系满足杆臂变换，最大位置误差 `5.11e-14 m`、姿态差
`1.31e-16 rad`；机体系速度符合 `v_B_new=v_B_old+omega_B×d`，误差小于 `1.19e-13 m/s`。
两套 Odom/TF 各 412 组逐条一致，新静态 TF 的平移与新 YAML 完全一致，进程正常退出。

这次重新运行滤波的初始数据前缀与实机首次运行不同，得到旧/新最大偏移
5.477/3.770 cm、RMS 2.129/1.292 cm，仅作为实际应用链检查，不混入前述原轨迹标定指标。
旁路接收原始/转换 IMU 各 8529 条，原始/转换点云 426/425 条；旁路未完整收到转换云，
不据此宣称全链路零丢帧，也不把它归因于外参修改。

详细数据在该 bag 的 `analysis/extrinsic_recalibration/`：原/新 YAML、原始轨迹、
新外参精确重表达 CSV、指标 JSON、时间审计 JSON、对比 PNG/PDF 与 ROS 回放验证结果。
分析和观察代码仅临时执行，不保留新测试/回放脚本；原始 db3 不修改。

`pcl_publisher` 已重新构建，安装 YAML 与源码内容一致。日常运行 `./scripts/odom.sh`
时转换节点和里程计读取同一新配置；正在运行的节点需要重新启动才会读取新外参。
`/bashlink/pcl` 与 `/baselink/imu` 继续发布，PTP 继续由独立系统服务管理。
