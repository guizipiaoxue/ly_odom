# Batch运动补偿状态雅可比

2026-10-15：按用户要求将补偿对速度/角速度的导数加入激光联合更新，同时传播其状态不确定度。
此前报告中的“冻结补偿”是修改前的实现，下面描述现行代码。

## 观测模型

维持30维状态/P：`[p,R,R_IL,t_IL,v,omega,a,g,bg,ba]`。`R`将IMU轴转到世界轴，
`v`为世界系速度，`omega`为IMU系角速度；两个旋转均采用右扰动。
保留原始激光点`p_L`和相对实际批末时间`dt=t_point-t_end<=0`。

在原有批内匀速/匀角速近似下：

```text
u = R_IL * p_L + t_IL
D = Exp(omega * dt)
q_end = D*u + R^T*v*dt
y = p + R*q_end = p + R*D*u + v*dt
r = n^T*y + d
z = -r
```

平面法向`n`、距离`d`来自历史地图；每批只在共同先验上线性化/匹配一次并联合注入一次。
这里冻结的是线性化点和匹配结果，补偿本身是状态函数。

令`C=R^T*n`、`N=D^T*C`、`Jr(phi)=A_matrix(-phi)`，预测残差的H为：

| 状态 | H块 |
|---|---|
| p | `n^T` |
| R | `(D*u × C)^T` |
| R_IL | `(p_L × R_IL^T*N)^T`，仅在线估计启用 |
| t_IL | `N^T`，仅在线估计启用 |
| v | `dt*n^T` |
| omega | `dt*(u × N)^T*Jr(omega*dt)` |
| a、g、bg、ba | 直接导数为零，通过P交叉项更新 |

姿态项不能继续使用`q_end × C`：对`R^T*v*dt`求导后，平移补偿随姿态的变化恰好抵消
`R*q_end`外层旋转造成的那一部分。角速度项保留SO(3)右雅可比，不能只用小角度叉乘近似。
`dt=0`时速度/角速度H严格为零，退化到原来的同时刻点到面观测。

## 状态不确定度与共享误差

堆叠全部点的完整H后，联合创新协方差为`S=H*P*H^T+R_meas`。
因此不仅包含速度、角速度的方差，也包含它们与姿态、位置、外参以及彼此的交叉项。
同一批内不同点共享运动状态，其补偿相关性保留在`S`的非对角块。

生产代码累加`Λ=Σ H_i^T*R_i^-1*H_i`及`η=Σ H_i^T*R_i^-1*z_i`，再通过先验P白化求解，
与堆叠全部点后进行一次稠密Kalman更新等价，不显式分配点数平方的S。
禁止把`H_motion*P_motion*H_motion^T`再次作为各点独立测量R加进去：这会重复计算状态误差，
并丢失其与位姿的交叉项和跨点相关性。

H载体由12列扩为18列`[p,R,R_IL,t_IL,v,omega]`；固定外参模式选择非连续索引
`[0..5,12..17]`求解12维，避免对严格为零的外参P块作Cholesky；在线模式选择前18维。
状态/P始终30维，未被直接观测的状态通过完整交叉协方差参与更新。两个SO(3)注入/reset保持。
独立激光噪声仍用原`laser_point_cov`，刚性补偿不改变其各向同性方差。

## 按文件的变更

| 文件 | 变更与用途 |
|---|---|
| `src/ly_lio/estimator.h` | 点载体保存原点/时间，统一提供补偿、世界点和18列H；避免观测与后验点采用两套模型 |
| `src/ly_lio/estimator.cpp` | 在同一批末先验上计算补偿/关联/完整H，并累加18维联合信息 |
| `src/ly_lio/eskf.h` | 固定12维/在线18维选块白化，使用全部30维P交叉项更新与reset |
| `src/ly_lio/ly_lio.cpp` | 批内保留原点/时间，更新后按后验v/omega/R/外参重算入图与注册云 |

后验点只按各自所属批的后验重算；后续批不会回头优化已经完成的批。
整扫描仍到scan_end才统一入图，不在当前扫描内建立自匹配约束。
批边界、IMU事件优先级、0.1ms设置、扫描末发布和传感器时间语义保持原流程。

使用生产头文件/核心动态库进行有限差分、独立稠密Kalman和核心合成扫描流程核对；
临时验证程序在验证后删除。未启动硬件或操作PTP，未测量本次修改后的真实零漂。

本次加入的是**当前补偿模型中的状态不确定度及交叉相关性**。模型仍假设批内匀速/匀角速，
没有额外建立批内随机过程轨迹与批末状态之间的条件分布，也未建模地图平面、关联与采样时间
的不确定度。不能因此声称物理去畸变误差已全部覆盖，或零漂一定降低。0.1ms下新增项的量级
随dt变小，实际精度收益需要同源静止/运动数据对比确认。
