# ly_lio 实现对照

## 当前算法与复现范围

本包独立实现 Point-LIO 的30维 IMU输出观测滤波路径，并吸收 Small Point-LIO 的
固定矩阵、标量激光观测、哈希地图和 ROS 2 封装。参考仓库仅用于对照，不动态包含兄弟
目录或外部 sentry 源码。第三方许可见 THIRD_PARTY_NOTICES.md。

2026-10-11 曾尝试相邻10ms窗口平面→平面模型，静止实机发生数十米发散。按用户最新
要求，当前恢复 **逐点 point→map**，窗口平面/Schmidt克隆已退出业务流程。
备用24维 IMU输入滤波路径、回环和独立实时IMU预测输出不在当前包内；不能称与原项目
所有分支、参数和性能完全一致。

## 数据如何变成位姿

1. 驱动点云保留真实点时间；预处理做标签、有限性和距离检查，空间降采样选择真实点，
   不平均运动中不同时间的XYZ。IMU保持原采样时间，单位按acc_norm换成SI。
2. 设备静止时估计重力方向、陀螺零偏和加速度模长偏差。清空标定前扫描，继续静止
   收集至少5帧、100有效点建立初图；等待期间的运动不能作为正确初图混入。
3. 跟踪阶段按传感器时间处理IMU、跟踪点、稠密点和扫描结束事件。状态预测使用
   `p_dot=v`、`v_dot=R*a+g`、`R_dot=R*[omega]x`；IMU观测为omega+bg及a+ba。
4. 每个跟踪点变至世界，在历史地图当前体素及6个面邻格找最近5点；PCA给出法向n和
   平面偏移d。残差是 `-(n^T * (R*(R_IL*p_L+t_IL)+p)+d)`。
5. 位置和右扰动姿态等组成雅可比，用当前协方差算标量创新方差和Kalman增益；
   注入位置/旋转误差并更新协方差。默认固定激光外参；可选在线外参需明确安装关系。
6. 同扫描的后验世界点先暂存，到扫描结束才加入地图。多点体素保留几何分布并去重，
   容量通过LRU限制，避免每格单点造成斜墙平面支持不足。
7. 每次观测与输出前把协方差推进至对应采样时刻。过程噪声采用
   `Q*process_noise_reference_dt*dt`，默认参考周期5ms，避免点数变多就意外缩小噪声率。
8. 内部得到IMU原点位姿T_WI；安装文件给T_BL、激光外参给T_IL，计算
   `T_BI=T_BL*inverse(T_IL)`、`T_WB=T_WI*inverse(T_BI)`，输出机体位置和四元数。
   Odom、TF、Path使用同一机体变换，速度和协方差包含杆臂的影响。

默认每帧末点发布一次 Odom/TF/注册点云，约10Hz；激光更新发生在多个点时刻。
启用逐点位姿发布仍受整帧交付延迟影响，不能当作低延迟实时100Hz预测。

## 时间、单位与标定限制

本项目 Livox 驱动输出加速度g，默认acc_norm=1；sentry驱动已经输出m/s²，接入时
需acc_norm=9.80665并使用同样的重力模长，不能再乘一次g。重力由滤波预测R*a+g抵消，
不是在传感器输入前删除。两项目默认共用PTP/TAI减37秒的UTC时间轴。

PTP不要求雷达与IMU采样时刻相同；逐点与IMU各自时间用于预测。静止录包可检查
回退、单位、覆盖与软件偏移，却不能可靠标定运动中的固定时延或内部激光→IMU外参。
目前内部外参使用单位阵假设；固定安装文件描述雷达→云台中心。活动云台不能用固定
变换自动得到真实底盘姿态。动态精度仍需有时间戳的关节角/独立参考与设备标定。
