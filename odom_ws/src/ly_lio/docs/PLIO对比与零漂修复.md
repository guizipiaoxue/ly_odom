Schmidt pose clone 保留前窗位姿边缘与交叉协方差；首窗只参考，缺窗不能跨跳。
外参只支持固定 lidar→IMU，历史地图不再作为滤波约束。

## 数据与评价口径

- 静止包：`bags/odom_20261011_161143_6cfa194f`，原始 1447 帧点云、28750 条 IMU。
- 云台转动包：`bags/odom_20261011_154652_bbb530d5`，原始 1003 帧点云、20049 条 IMU。
- 只读取 `/livox/lidar`、`/livox/imu`，不使用原里程计、TF 或 Path 作为算法输入。
- 原始加速度为 g；ly_lio 用 acc_norm 换算，PLIO 适配器乘一次 9.81。
  两者都在滤波预测中补偿重力，不在输入端预先扣除。
- 原始逐点时间为 FLOAT64 相对纳秒；ly_lio 按包头加相对时间解码，PLIO 适配为相对秒。
- PLIO 的双雷达 IMU 校正旋转/有效杆臂禁用；两者采用相同 lidar→IMU 单位外参假设。
- 先估计 IMU 原点状态，再用同一 `pcl_ws/config/lidar2baselink.yaml` 得到安装中心位姿。
- 静止窗口固定为原 `stationary_samples.npz` 的传感器时间
  `1791706369.6983774` 到 `1791706429.6994534`，约 60.001 秒。
  首末各5秒平均求位置端点和 SO(3) 姿态端点，最大偏移/RMS 相对首段平均位姿。
- 原版和修复版比较使用相同确定性离线调用顺序；不把旧实机结果与新离线结果直接混比。
  原实机末端6.66 cm与离线6.82 cm的小差别来自回调/输入排队及评价端点定义。
- PLIO 因抽样后的扫描末点时间不同，共同窗口内600帧，ly_lio 为601帧。

## 与参考 PLIO 的差别

| 机制 | 旧修复前 ly_lio | 参考 PLIO | 旧逐点地图修复 ly_lio |
| --- | --- | --- | --- |
| 静止初始化 | 只估计重力，bg/ba 为零 | 静止门限并初始化 bg/ba | SI 门限、最近窗口估计 bg/ba、连续静止段建初始地图 |
| 点云采样 | 同体素坐标和时间取平均 | 保留距中心最近的真实点 | 保留原坐标/时间对，串并行确定 |
| 协方差时刻 | IMU 时刻才传播，激光更新用滞后 P | 点时间组和 IMU 都传播 | 每个激光/IMU观测和扫描结束都同步 P |
| 过程噪声 | Q·dt² | Q·dt² | Q·dt_ref·dt，dt_ref=.005s；保持原200Hz标定方差率 |
| 局部地图 | 每格1点，7格找最近5点 | 每格最多128点，7格查询 | 每格最多20点，间距至少5cm，LRU，7格找最近5点 |
| 地图插入 | 每个点更新后立即加入 | 扫描结束加入 | 每点保存后验世界坐标，scan_end才加入历史地图 |
| 初始地图 | 点数达到门限即建图 | 累积5帧 | IMU静止段覆盖的有效点建图 |
| 实现 | 固定30维顺序ESKF | IKFoM，maximum_iter=1 | 固定30维顺序ESKF、稀疏F精确左右乘 |

参考保留其他默认配置：地图0.30m、采样体素0.15m、输入stride=2、最多2000个跟踪点、
2ms点时间组、100条初始化IMU、重力9.80665。
对比时的旧LY版本用地图/采样体素0.20m、stride=1、不限制到2000点、200条初始化IMU、重力9.81。
因此这是同源输入下的实际配置对比，不能把所有差异都归因于一个算法参数。
参考没有多轮迭代优势；两边既有更新都未加入 Joseph 或显式 SO(3) 后验协方差重置。

## 旧逐点地图模型修复证据

1. 含稳定陀螺零偏和0.4%加速度模长误差的真实核心测试，原实现初始化后仍 bg=ba=0，
   随后出现虚假角速度/速度；修复后残差为零。明显旋转/振动启动会等待静止。
   但这一项单独并未改善60秒稳态零漂，不能将其称为本次漂移的主要原因。
2. 45°墙面穿过对角体素，单点地图在7格中最多找到3点，整面无法拟合；
   多点体素使最近5点具备非共线平面分布。同格去重避免重合点伪造约束。
3. 激光时刻之前未传播 P 会遗漏 p/v 交叉增益；点更新之后到下一 IMU 只能传播剩余区间。
   新测试用解析二维 Kalman 解和独立30维随机SPD稠密公式验证。
4. 每点调用旧 Q·dt² 会把过程噪声随点密度增大而缩小；改用参考周期方差率。
   bg/ba直接随机游走在1、200、10000段下累计一致，但一阶 F/状态仍存在离散误差。
5. 同帧点不能立即成为后续点的历史地图约束；扫描结束作为第四类事件处理。
   两个积压扫描原来合并发布一次，现在分别输出自己的点云、里程计和时间戳。
6. 初始化切云不能只用最近N条IMU的起点：回调成批到达时，会排除已经静止的早期扫描。
   当时的修复版向前扩展与合格窗口一致的连续IMU段，遇运动停止；真实 ROS 集成验证能够初始化。

核心和配置均有中文注释；此前新增回归测试已按用户要求删除。没有添加静止位姿锁定或强制零速度。
初始化门限仍可能接受极慢旋转，实际启动必须保持传感器静止；单姿态只辨识
陀螺零偏和沿重力方向的加速度模长残差，不等于完整加速度计标定。
