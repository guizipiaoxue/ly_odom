# 24维清理、地图参数筛选与10分钟零漂

2026-10-12。按用户要求删除在线30维代码，并继续调参、进行600秒实机静止测量。
本轮不接轮速，不加持续零速锁定，不修改安装外参或PTP配置。

## 真正24维实现

状态排列改为 `[p,R,v,omega,a,g,bg,ba]`，共24维，协方差为24×24。
外参R_IL/t_IL只保留在固定配置中，不再作为状态字段，也不保留6个空协方差行列。
删除在线激光批点载体、12列观测信息更新、外参先验参数、外参误差注入及旋转reset。
固定Batch的6列位姿观测、IMU输出观测和完整物理交叉协方差继续保留。

节点通过核心只读固定外参接口组合 `T_BI=T_BL*inverse(T_IL)`，
body位姿、速度及协方差使用新的24维索引。Odom/TF、点云、终端与话题语义不变。
旧 `extrinsic_est_en=false` 仅为兼容读取；true会明确报错，当前没有在线外参分支。
原实验报告和测量数据保留为历史，不再提供可用的30维代码入口。
这里的24维是包含角速度、比力及IMU零偏的输出观测模型，
不是Point-LIO另一条24维IMU输入预测路径。删去固定外参的6维零协方差占位
减少了无用存储和分支，但与旧固定模式数学等价，不能将现场零漂变化归因于降维本身。
本次仍使用原配置的单位T_IL；若配置非单位内部外参，雷达与IMU应使用不同帧名，
并提供对应固定TF。现有节点只自动发布body→IMU，不会替同名输入定义两个不同的物理坐标系。

## 调参方法

上一轮噪声参数候选未能通过跨录包验证，本轮改查地图的几何支持与初始化，
不重复压低IMU噪声来追求静止曲线。训练使用191716原始录包的固定60秒窗口，
共15组：默认1组、单项12组、组合2组。

| 参数 | 本轮尝试值 |
|---|---|
| 地图最小点距m | 0.02、0.03、0.05（原默认）、0.075 |
| 每格最多点数 | 20（原默认）、30、40 |
| 跟踪空间采样m | 0.10、0.15、0.20（原默认）、0.25 |
| 地图格边长m | 0.15、0.20（原默认）、0.25 |
| 初图扫描数 | 5（原默认）、10 |
| 静止IMU初始化样本 | 200（原默认）、400 |

另外比较点距0.02+每格30、点距0.02+采样0.25两组组合。
候选仅按训练结果冻结，随后用190342静止录包和211347云台旋转录包验证；
初始化/外参/传感器输入顺序一致，不用新现场600秒数据反向挑参数。

原默认训练末端/最大/RMS为1.002/2.382/1.579cm；点距0.02单项为0.702/2.269/1.382cm。
每格30组合RMS为1.378cm，与单项相近但末端较差，因此优先检查只改点距的候选。
这些是60秒训练结果，不能直接当成10分钟精度保证。

## 600秒测量口径

用户确认雷达、云台和底盘保持静止；首个有效Odom后预热5秒，再测足600秒传感器时间。
正式窗口固定后不按轨迹好坏选择子窗。位置参考为首5秒均值，末端为末5秒均值之差；
最大偏移和RMS相对同一个参考，姿态用四元数均值比较。
另保留每分钟趋势及末60秒均值，避免只看最后一个瞬时值。

实机通过统一 `scripts/odom.sh` 启动驱动、转换、24维里程计与全话题录包；
只关闭终端面板。PTP仅只读检查，采样结束统一Ctrl+C并等待录包metadata写出。
结果需区分现场输出与同一新bag的离线回放：录包发现原始话题可能晚于节点启动，
不同初始化前缀的轨迹不能直接视为同一次确定性输出。

因此不是提前停止后按10分钟折算。首末5秒分别含51/49个实际样本。
