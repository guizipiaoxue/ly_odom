# 24维Batch与固定外参验证

2026-10-17。最终范围按用户最新补充：暂不做plane-to-plane，不接轮速；采用论文的
逐点点到历史地图平面残差，在同一Batch中合并后一次联合更新。

## 最终实现

- 状态及误差P真正为24维`[p,R,v,omega,a,g,bg,ba]`，流形`SO(3)×R^21`。
  删除外参状态、误差索引、六行列协方差占位及在线外参注入/reset分支。
- IMU仍作六维输出观测，角速度和比力分别与对应零偏求和；达到量程95%的轴单独屏蔽。
  传播先P后x，激光/IMU按真实时间处理，同stamp先IMU，Batch遇IMU事件提前结束。
- MID360配置和C++缺省统一1ms（0.001s），保留原空间采样、地图、独立点噪声和速度
  噪声率0.1。没有2000点上限。合格点各自查询历史5近邻PCA平面并计算标量残差/H，
  累加信息后仅一次注入；H直接覆盖[p,R,v,omega]12列，通过完整24维P更新其他状态。
- 固定外参保存在估计器配置中。`extrinsic_T`是IMU原点在雷达系的位置c_L，单位m；
  读取一次换算`t_IL=-R_IL*c_L`，内部始终`p_I=R_IL*p_L+t_IL`。
  当前YAML原值`[0.011,0.02329,-0.04412]`保持；R_IL=I时内部平移
  为`[-0.011,-0.02329,0.04412]`。缺省约定改为imu_in_lidar；显式lidar_in_imu
  仍可迁移旧配置。MID360/L2两份当前YAML统一为IMU在雷达系的位置（L2为零向量）。
- 机体安装关系T_BL固定，启动时组合T_BI；输出位姿/速度/协方差按24维状态计算。
  静态TF仍为实际T_BL。reset与IMU缺段重建不改变配置标定。
- 邻点不足或匹配失败时该点不参与激光更新，仍按后验补偿进入本扫描地图增量；统一在
  scan_end插入，不让本扫描点成为扫描内其他点的匹配参考。无新匹配时继续预测/IMU观测。
- 旧extrinsic_est_en=false告警兼容；true和已移除的外参先验参数明确启动拒绝。
