# 最新录包中 IMU 与激光对里程计的作用

分析日期：2026-10-13。录包：`bags/odom_20261013_210508_29408d49`。

**在这份约 223 秒的近静止数据中，激光是维持位置不发散的关键约束；IMU，尤其陀螺仪，对角速度估计和姿态平稳性有明显作用。** 不能用一个统一百分比表达两者的决定权，也不能把静止结果外推为运动精度。

## 1. 现场参数和数据

`/parameter_events` 捕获了 82 条启动声明；当前 `config/mid360.yaml` 的 67 项配置均能在录包中确认，逐项一致，没有参数修改事件。关键值为：

| 参数 | 录制时 / 当前值 |
|---|---:|
| 状态 / IMU 观测维度 | 30 / 6 |
| `lidar_batch_duration` | 0.0001 s，即 0.1 ms |
| `laser_point_cov` | 0.001 m² |
| `imu_meas_omg_cov` | 0.001 (rad/s)² |
| `imu_meas_acc_cov` | 0.01 (m/s²)² |
| `omg_cov` / `acceleration_cov` | 1000 / 500 |
| `bg_cov` / `ba_cov` | 0.0001 / 0.0001 |
| `process_noise_reference_dt` | 0.005 s |
| 降采样点距 / 地图格长 | 0.10 / 0.20 m |
| 每地图格最大点数 / 最小点距 | 32 / 0.05 m |
| 在线外参 | 关闭，固定用户提供的芯片位置 |

外参保留 `extrinsic_T=[-0.011,-0.02329,0.04412] m`，约定为 `imu_in_lidar`；内部激光→IMU平移为 `[0.011,0.02329,-0.04412] m`。安装输出仍使用同一 `lidar2baselink.yaml`，不接入轮速。

完整录包约 232.98 秒，原始 IMU 45988 条、原始点云 2300 帧、现场 Odometry 2294 条。原始 IMU 无重复、倒退或大缺段，最大间隔约 6.04 ms；全部轴的饱和次数为 0。2294 组 Odom、TF、注册云 stamp 完全相同，TF 数值差为 0，未见重置/告警。

现场首输出后去掉 5 秒，余下 224.2 秒；首末各 5 秒均值比较：位置末端变化 **0.430 cm**，位置 RMS **0.488 cm**，最大 **1.319 cm**；姿态末端变化 **0.01447°**。输入和输出都支持“近静止”，但录包没有独立机械运动真值，以上是相对变化，不能自动解释为真实误差。

原始流缺少现场初始化使用的启动前缀：现场首输出仅在录到的首条原始 IMU 之后约 0.606 秒。因此离线回放重新标定/建图，初图 15989 点，与现场初图 18041 点不同。以下实验之间同源、同初始化，**不把现场输出直接当作消融基线**。

## 2. 实验方法

从最新 db3 只读取得 `/livox/lidar` 与 `/livox/imu`，按录包接收时间和消息 id 顺序反序列化；使用生产 PointCloudDecoder、LyLio 核心及机体杆臂输出函数，每条输入后执行 `handle_once()`。

冻结当前配置和安装外参，进行七组回放：当前参数、激光 R×10、两项 IMU R×10、仅陀螺 R×10、仅加计 R×10、停止激光更新、停止 IMU 更新。保持 Q、采样、Batch、真实时间和初始化方法相同。R 是方差，×10 对应标准差×√10。

停止观测的两组先完成共同初始化及 5 秒融合热身，再屏蔽相应更新；保留原始输入、事件时序、预测、去畸变和地图流程。停止 IMU 更新仍保留初始化和热身获得的惯性先验，因此不代表从启动起的纯激光算法。停止激光更新也不代表拔掉点云输入。

所有七组均输出 2285 帧，同 stamp，0 次重置，数值有限。共同热身至消融边界前，停止观测的两组与基线全部轨迹字段逐数一致。插桩与未插桩的已安装生产核心，前 650 帧全部输出字段逐数相同，最大差 0；在这 650 帧检查范围内，探针没有改变滤波数值。

统计去掉首输出后的前 5 秒，得到 223.30 秒窗口；参考位置与姿态分别取该窗口首 5 秒的位置均值和四元数均值，末端取最后 5 秒均值。姿态变化使用 SO(3) 最短旋转角；RMS/最大值均相对首均值。这里没有静止锁定、零速观测或强制清零。

## 3. 同源结果

| 回放设置 | 位置 RMS / 末端 / 最大，cm | 姿态 RMS / 末端 / 最大，° |
|---|---:|---:|
| 当前参数 | 0.4605 / 0.4708 / 1.2735 | 0.05216 / 0.01193 / 0.11956 |
| 激光 R：0.001→0.01 | 0.4583 / 0.4539 / 1.2360 | 0.03394 / 0.00732 / 0.09089 |
| 两项 IMU R×10 | 0.4776 / 0.4837 / 1.3033 | 0.07866 / 0.02640 / 0.19515 |
| 仅陀螺 R：0.001→0.01 | 0.4848 / 0.4931 / 1.2756 | 0.07881 / 0.02572 / 0.17858 |
| 仅加计 R：0.01→0.1 | 0.4559 / 0.4779 / 1.2138 | 0.05200 / 0.01298 / 0.11738 |
| 共同热身后停止 IMU 更新 | 0.5512 / 0.4884 / 1.7622 | 0.30287 / 0.06205 / 1.54449 |

停止激光更新后，位置迅速发散，下面直接相对共同热身边界位姿比较，避免均值窗口掩盖发散初期：

| 距边界的实际传感器时间 | 位置变化 | 姿态变化 |
|---|---:|---:|
| 5.10 s | 0.401 m | 0.531° |
| 10.10 s | 3.033 m | 1.061° |
| 30.10 s | 80.12 m | 3.164° |
| 60.10 s | 639.6 m | 6.362° |

这些是停激光更新的离线估计发散，不能解释为设备实际移动。停止 IMU 观测则仍保留厘米级位置，但姿态 RMS 从 0.05216° 增加到 0.30287°，约 5.81 倍，最大姿态变化达到 1.54°。这说明该近静止段中，激光可以支撑位置，而 IMU 对姿态稳定有实质作用。

参数敏感性也支持这个区分：两项 IMU R×10 的姿态退化基本由陀螺 R×10 重现；仅加计 R×10 对姿态 RMS 影响很小。激光 R×10 的位置 RMS 几乎不变，姿态 RMS 降低约 34.9%。逐帧姿态角增量 RMS 也从约 0.04368° 降为 0.02122°，说明较弱的激光观测在此包中减少了姿态波动；更平滑不等于动态更准确。

## 4. 滤波内部权重说明

临时核心探针记录每次成功更新的状态修正和协方差缩减。缩减按同一更新先验与 **SO(3) reset 前** 的后验比较；以下位置/姿态对应核心 IMU 原点状态。均值使用全部更新，CSV 分位数每 100 次抽样一次。

窗口内约 129.12 万次成功激光 Batch 更新、4.47 万次 IMU 更新。单次更新的平均三轴协方差 trace 缩减为：

| 状态 | 一次激光 Batch 更新 | 一次 IMU 更新 |
|---|---:|---:|
| 位置 | 0.1071% | 0.01588% |
| 姿态 | 0.7534% | 23.424% |
| 角速度 | 0.1079% | 96.126% |
| 比力 | 约 0.00000316% | 65.132% |

两种更新的时间、次数和先验不同，这张表是当前滤波模型的**条件约束强度**，不能把数值累计归一化为“传感器占多少票”。点云和历史地图的相关性也可能使内部协方差偏乐观。0.1 ms 小批次单独经常秩亏，单批最小信息特征值接近 0，不足以认定整个场景几何退化。

IMU 观测直接约束 `omega+bg` 和 `a+ba`；激光 H 直接含位置和姿态。完整 P 的交叉项使 IMU 更新影响姿态、激光更新反过来影响角速度及零偏，因此两者不是各自独立的投票器。

本包中 `K_omega` 对角均值约 **0.9613**，`K_a` 约 **0.6546**，说明 IMU 每次更新对角速度/比力状态的修正很强；这不表示“姿态 96% 来自 IMU”。原因之一是当前 Q 较大：名义 5 ms 传播给 omega/a 增加约 0.025/0.0125 方差，再与陀螺/加计 R=0.001/0.01 融合。不能看到某项 R 大就判断 IMU 没作用。

实际 IMU 每 1 秒去均值后的三轴标准差：陀螺 `[0.007060,0.002070,0.001566] rad/s`，加计 `[0.038586,0.060545,0.102543] m/s²`。这可作噪声标定参考，但单段统计不能完整区分振动、零偏、温漂及模型误差，更不能与激光 R 跨单位比较。

## 5. 参数调整的含义

本次只分析，没有修改业务代码或默认参数。若下一轮目标是减少近静止姿态波动，`laser_point_cov=0.01` 是值得验证的候选；它在本包改善姿态波动且位置基本持平。应在另一个静止包和旋转/平移包上验证后再决定默认值。

此包不支持通过增大 `imu_meas_omg_cov` 减弱陀螺来改善姿态：×10 后姿态 RMS 增大约 51%。仅加计 R×10 的影响较小，也不足以证明可以忽略加计；它仍负责运动预测和重力补偿。Q 与 R 要配合调整，当前结果不能给出唯一最优值。
